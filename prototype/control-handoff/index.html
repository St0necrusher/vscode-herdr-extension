Who controls this Herdr Pane?

Question: Can VS Code make terminal handoff feel automatic without stealing control from Ghostty or losing what the user typed? This prototype tests a proposed policy: observe by default, acquire on typing only when uncontested, require an explicit takeover on conflict, and release when VS Code stops being the active place of interaction.

Policy under test

Focus is evidence that VS Code may release control, but not permission to displace another controller. The first typed input may wait briefly while VS Code requests unowned control. If somebody else controls the Pane, that input is discarded and takeover requires a separate explicit action. Reconnect always returns read-only.
