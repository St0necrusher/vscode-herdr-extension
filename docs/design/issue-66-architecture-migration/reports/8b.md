## Criteria and implementation

- **Keep fields only for objects needed after construction:** `sessions` and `takeoverPluginRegistration` remain fields for `initialize()` (`src/extension/HerdrExtension.ts:41-42,121-128`). The other composition objects are local `const`s or passed directly to `acquire()` where no later reference is needed. `disposables` stores lifecycle ownership (`:40`); `disposed` preserves idempotence (`:43,132-137`).
- **Track acquired disposables immediately:** each disposable is passed to the local `acquire()` at construction (`:48-52,53-110`). Non-disposable settings, plugin-registration state, and pane-client factory are not added to the list.
- **Use one cleanup list in both paths:** constructor failure releases `disposables` and rethrows the original error (`:113-118`); normal `dispose()` releases the same list after the existing idempotence guard (`:132-138`). No tests, manifests, or command registrations were changed.
- **Construction order:** retained from logger/settings and takeover setup, through Sessions and status, Pane Editor dependencies, workspace/navigation views and features, ending with reveal-pane (`:53-112`).

The local `acquire()` inserts later resources at the list front, yielding reverse construction order where that matches the old behavior. Resources constructed after `TakeoverPopupHost` but before `PaneTerminalSurfaceManager` are inserted immediately after the popup; the manager and all later objects are inserted ahead of it. This explicitly preserves the non-reverse segment `PaneTerminalSurfaceManager → TakeoverPopupHost → PaneEditorFocusTracker`. Thus normal disposal releases the full sequence above (`:135-137`). On constructor failure, the catch releases the acquired resources in this same relative order: before the manager exists the popup remains before the acquired focus/selection/status/Sessions resources; once the manager exists it is before the popup, which remains before the focus tracker. The list naturally omits objects whose construction had not completed, matching the old optional-resource cleanup (`:114-117`).
