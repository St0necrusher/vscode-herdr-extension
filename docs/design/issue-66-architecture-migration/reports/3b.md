## Done criteria and architecture

1. **Old layers removed:** all remaining files were moved with plain `mv`; the obsolete capabilities entry was deleted and empty directories removed. Both old top-level directories are absent.
2. **Pane Editor ownership:** `src/modules/pane-editors/` contains the selection model, focus tracker, terminal surface and its colocated test, manager, `paneTarget`, and `paneClientPolicy`. Attach/Observe and takeover-offer decisions remain unchanged in the module.
3. **Module dependencies:** production imports reach only the module itself, `@api/herdr`, `@core/logger`, and the external VS Code package. There are no peer-module imports. `session-source.ts:3-30` declares the active Session projection variants, its read/change subscription, and the narrow `pane.moved` subscription. `SessionsModel` continues to satisfy these structurally; composition passes the same instance without an adapter.
4. **Streaming clients:** `src/api/herdr/pane-clients/` owns Attach, Observe, their factory, and `PaneOutputSink`. The factory reads `configuration.read().executable` on each creation exactly as before, with no captured startup value or import from Sessions.
5. **Shared executable dependency:** the existing `HerdrExecutableSource` moved from takeover to `api/herdr/shared/herdrExecutableSource.ts`. Both takeover consumers and the factory import it through `../shared`. It is not added to the external Herdr public entry because no external consumer needs to name it.
6. **Core litmus:** `core/process/stopWithEscalation.ts` takes only an exit promise, a signal callback, and wait durations; it knows neither Herdr nor Pane Editors. An unrelated project could copy it unchanged. It is exported through `@core/process`, which both streaming clients use.
7. **Public entries:** `modules/pane-editors/index.ts` exports construction resources and the former opening, closing, and presence types. `api/herdr/index.ts` exports the streaming factory and the client/sink types used by the module. Concrete Attach/Observe classes remain directly importable by integration tests, without production exports added solely for tests.
8. **Composition and consumers:** `HerdrExtension.ts` changes imports only; construction and disposal are unchanged. Old navigation consumers temporarily import the Pane Editor public entry, as briefed for slices 4 and 5.
9. **Tests and scope:** all modified existing test files change imports only. Comparing the moved surface test with its HEAD predecessor also shows only import changes. No assertion or test title was changed. The diff contains only owned moves/new files, consumer imports, and this report; ESLint configuration is unchanged.
