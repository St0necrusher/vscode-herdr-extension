- `src/features/navigation/agents/view/VsCodeAgentsView.ts:67–77` never assigns contextValue. No Agent regex menu exists. The added test explicitly pins that absence instead of inventing a context.

No Herdr-owned npm tree item exists to build through a real view class. Existing npm command tests continue to pass, but no new fabricated npm row test was added.
- The real Panes model can only produce closable Pane rows inside a multi-Pane Tab; therefore the real-view test observes five reachable Panes context variants, not `herdr.panes.pane` without `.closable`. The exported row constructor could represent that context with artificial data, but doing so would not characterize reachable model behavior.

Proposed resolution: accept these as explicit current-behavior limitations of criterion 2; keep production and package.json unchanged. If the coordinator wants a separate assertion for the externally owned npm menu equality or artificial nonclosable grouped-Pane construction, that is a follow-up clarification rather than a production change.
