### What these rules cannot establish

- Boundaries checks dependency edges, not whether code is semantically generic, represents a scenario/domain/surface, or belongs in the nearest common ancestor based on actual reuse.
- The plugin's full-path recursive descriptors do not provide a usable recursive parent chain, and their element-relative paths can start at the first child rather than the deepest part. Therefore directions use captured block identity, lexical relative import patterns, and resolved file paths instead of parent-relationship selectors. Deep child and shared cases were checked explicitly.
- The configuration enforces ordinary canonical relative paths, not every equivalent path with redundant traversal segments. Review remains necessary for unusual path spellings.
- `import-x/no-cycle` detects runtime/value cycles, not TypeScript-only cycles (type imports are ignored by that rule).
