# Ответы по этапу 5a

## 1. `paneName` — D16

**Решение:** принять размещение в `modules/pane-editors` и публичный экспорт для Views и Features. Сохранить тело функции без изменений. Если `paneTerminalOpenRequest` и другие самостоятельные части модуля используют эту функцию, разместить её в `modules/pane-editors/shared/` и экспортировать через публичный вход модуля; не вводить соседний импорт между частями.

**Причина:** правило имени используется и для строк, и для открытия редактора; оно не принадлежит одному View. Размещение в модуле устраняет запрещённый импорт Features → Views. Внутреннее размещение подчиняется ARCHITECTURE §3.

## 2. Удаление `NavigationPaneOpening` — D17

**Решение:** принять чистую функцию `paneTerminalOpenRequest(sessionId, pane)` в `modules/pane-editors` и минимальное изменение `ScriptsFeature` в 5a2. Функция только строит запрос; поиск Pane и обработка его отсутствия остаются у вызывающего кода. Сохранить чтение текущего контекста в тот же момент, поддержку connected/Stale и прежние ошибки. Включить изменение Scripts в проверяемый diff 5a2 и передать обновлённое исходное состояние этапу 5b.

**Причина:** построение запроса относится к операции открытия редактора. D10 запрещает получать эту операцию через другую фичу. Изменение потребителя в том же этапе позволяет удалить старый контракт без временного посредника.

## 3. Аргументы команд и тест — D18

**Решение:** принять структурные аргументы с идентификаторами, добавление `tabId` в `PanesGroupTreeItem`, размещение `herdr.openAgentPane` в `features/reveal-pane` и замену конструкции `PanesFeature` на `VsCodePanesView` в `pane-command.test.ts` без изменения assertions. Замена проверки класса на проверку нужных полей разрешена как изменение границы команды. Это не разрешение менять доступность действия: сохранить проверки текущей Session, Selected Space, актуальности, наличия объекта и closability. В частности, Close Tab сохраняет проверку группы, а не принимает любой объект только потому, что у него есть `tabId`. Команда `herdr.openPane` сохраняет существующий строковый аргумент; не заменять его объектом ради единообразия.

**Причина:** Features не импортируют классы Views; выбор Space и открытие редактора являются сценарием согласования модулей. Тест продолжает проверять тот же путь: дерево → зарегистрированная команда → запрос открытия. Меняется владелец этого пути, а не проверяемое поведение.
