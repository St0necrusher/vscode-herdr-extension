# Ответ по этапу 5a2

## Q1. Имена файлов входов фичи — D19

**Решение:** применять правило именования из ARCHITECTURE §6. Для файлов с функциями использовать `closePane.ts`, `closeTab.ts`, `renameTab.ts`, `splitPane.ts`. Для файла, основной экспорт которого — класс, использовать `PascalCase.ts`. Имена каталогов фич остаются в kebab-case.

**Причина:** §4 определяет разбиение на отдельные входы, а §6 прямо определяет имена файлов. Пример в §4 содержит несогласованное написание, а не исключение из правила.

В том же PR исправить пример §4 на `closePane.ts`, `closeTab.ts` и обновить соответствующие импорты после переименования файлов. Это исправление примера документа, не изменение архитектурного правила или поведения. Assertions тестов не менять.
