- **`modules/pane-editors/`**: `PaneEditorSelectionModel`, `PaneEditorFocusTracker`, `PaneTerminalSurface` (+ test; the Attach/Observe decision and the takeover offer decision stay here), `PaneTerminalSurfaceManager`, `paneTarget`, `paneClientPolicy` (Observe vs Attach is a module rule, `ARCHITECTURE.md` §2 table).
  - **`session-source.ts`** (named in issue #66): the module's own narrow dependency types for what it reads from the Session — the active Session projection and the `pane.moved` subscription. The peer rule forbids importing `@modules/sessions`, also for types (D10). `SessionsModel` satisfies them structurally; composition passes it as today. Herdr data types come from `@api/herdr`.
  - **Public entry** `modules/pane-editors/index.ts` exports what other blocks use: the manager's opening, closing and presence operations and the types from `src/capabilities/terminalSurfaces/*` (`PaneTerminalOpening`, `PaneTerminalOpenRequest`, `PaneTerminalClosing`, `PaneEditorPresence*`, `PaneEditorReference`), plus what composition constructs. Consumers in old `features/navigation` import it for now; slices 4 and 5 give them their own dependency types. Then delete `src/capabilities/`.
