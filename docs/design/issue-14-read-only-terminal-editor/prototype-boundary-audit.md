**Missing evidence / limits:** The prototype uses a manually entered target, not the real Panes View or Session+terminal-ID reuse. It did not test malformed-record handling exhaustively, bounded retry under long failures, or multiple editors. Its documented controller, takeover, input, and resize behavior is outside #14's read-only scope. Supported CLI syntax/record constraints should be checked against Herdr's versioned public docs before final architecture approval/implementation; this audit does not claim unpublished fields are stable.
